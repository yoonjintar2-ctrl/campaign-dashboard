셀을 드래그로 범위 선택한 뒤 Ctrl+C / Ctrl+V로 복사·붙여넣기 할 수 있습니다. 한 칸을 복사해 여러 칸에 붙이면 선택 범위 전체가 같은 값으로 채워지고, 엑셀에서 여러 셀을 복사하면 표에 그대로 펼쳐집니다. 구분·매체·광고상품·타겟팅·제품은 캠페인 설정에 등록된 항목만 사용할 수 있습니다. 일자가 해당 라인의 집행 기간을 벗어나면 행이 붉게 표시되고 다른 탭으로 이동할 때 알려 드립니다. 소진비용은 Gross로 입력하고 Net은 설정의 수수료율로 자동 역산됩니다. Ctrl+Z로 되돌리고 Ctrl+Y로 다시 실행하며, 방향키로 셀을 옮기고 Shift+방향키로 범위를 넓힐 수 있습니다.

☑ 예상 노출·클릭·조회 옆 체크 = 게런티(보장) 지표 저장됨
ⓘ
작성 요령 — 1개 행(라인)은 예산을 배분하는 기준으로 나눕니다. 타겟팅 그룹이나 소재를 매체가 자동으로 예산 최적화하는 경우에는 나누지 말고 한 개의 라인으로 적어 주세요. (여러 타겟팅·소재는 한 칸에 쉼표로 나열합니다.)
키보드 — 셀을 한 번 누르면 선택, Enter(또는 더블클릭)로 입력 시작, 다시 Enter 로 완료하면 셀 선택 상태로 돌아옵니다 · 방향키 셀 이동 · Ctrl+Z / Ctrl+Y 실행 취소·다시 실행
※ Gross 예산과 수수료율(대행사 + 렙사)을 넣으면 Net이 자동 역산됩니다 (Net = Gross × (1 − 합산 수수료율)). Value(밸류)는 직접 입력하며, 보너스는 Gross와의 차액으로 맞춰집니다.
※ 미디어믹스 표는 대시보드 › 미디어믹스 시트에서 확인합니다.
