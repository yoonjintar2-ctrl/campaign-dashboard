이 폴더 안의 파일을 깃허브 리포(campaign-dashboard) 에 **그대로 덮어쓰기** 하면 됩니다.
GitHub 웹에서 리포 → Add file → Upload files → 이 폴더의 내용물(src · tools · guide · README.md)을
끌어다 놓고 Commit changes. 같은 이름의 파일은 새 것으로 바뀝니다.

올라가는 것
  src/01-head.html … src/15-i18n.js   화면 소스 (15개) — 이번에 전부 바뀜

  guide/guide.html · guide/사용가이드.pdf  사용 가이드
  README.md

일부러 뺀 것 (리포에 있는 그대로 두세요)
  config.js                 — 실제 값은 GitHub Secrets 에서 채워집니다. 덮어쓰면 안 됩니다.
  .github/workflows/pages.yml — 지금 리포의 것이 정상 동작합니다. 건드리지 마세요.
  index.html                — push 하면 Actions 가 src 로 자동으로 다시 만듭니다.
